# Screenshots for the main README

Drop images into this folder with the exact names below, then open the main
`README.md`, find the matching block in its **Screenshots** section — each
slot is two lines, an image tag plus its caption — and delete the `<!--` and
`-->` comment markers around that block. The image appears on the repository
homepage the next time you push.

| Filename | What to capture |
|---|---|
| `studio.png` | The studio with a finished doodle ready to print |
| `make-a-change.png` | The *Make a change* box with a strip of earlier versions beneath a picture |
| `characters.png` | The saved-characters gallery with their caricature portraits |
| `badge-sheet.png` | The badge sheet: repeated 58 mm circles on A4, cut lines included |
| `printed-and-coloured.jpg` | A printed page, coloured in — a phone photo is perfect |

PNG suits screen captures; JPG suits photographs. Keep each image roughly
1200–1600 px wide so it stays sharp on the README without being enormous.
Any extra screenshots you want to add can live here too — reference them from
the README as `docs/screenshots/<name>.png`.
